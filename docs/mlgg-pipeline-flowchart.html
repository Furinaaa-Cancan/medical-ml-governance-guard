MLGG 9-Phase Pipeline

Cross-Sectional Data (e.g., NHANES) — From Raw CSV to Publication-Grade Report — 33 Fail-Closed Gates — 17 Analysis Tools

P1
Phase 1: Data Understanding & Cohort Definition
cohort_definition_gate.py — Layer 0
  • Load raw CSV → verify target column is binary (0/1) MLGG-C01
  • Define eligible cohort: exclude structurally impossible outcomes
    e.g., deceased patients cannot be readmitted; newborns in diabetic dataset
  • Sample size: Riley 2019 three criteria Riley 2019
    C1: shrinkage factor ≥ 0.9 → n ≥ p/((1-S)×φ)
    C2: R² optimism ≤ 0.05 → n ≥ p/0.05
    C3: risk precision CI ≤ 0.05 → n ≥ φ(1-φ)/(0.05/1.96)²
    EPV < 5 → FAIL | EPV 5-10 → WARNING riley_sample_size()
  • Auto-detect data types: numeric / binary / categorical / constant / id_or_text
  • Missing value profile: per-feature % missing, flag > 50% MLGG-P06
  • Detect longitudinal vs cross-sectional: patient ID duplicates?
→ cohort_summary.csv  |  feature_profile.csv  |  cohort_definition_report.json
P2
Phase 2: Data Splitting
split_data.py + split_protocol_gate.py — Layer 3
  • Patient-level disjoint split: same patient → same split MLGG-S01
  • Strategy for cross-sectional data:
    --strategy stratified_grouped --cross-sectional
    Stratified by outcome label, grouped by patient_id, random shuffle
    Temporal ordering checks automatically skipped
  • Default ratio: Train 60% / Valid 20% / Test 20%
  • Safety checks:
    • min 20 rows, 10 pos, 10 neg, 5 patients per split
    • Prevalence drift > 10% → WARNING
    • Any patient ID overlap → FAIL
→ train.csv  |  valid.csv  |  test.csv  |  split_protocol_report.json
P3
Phase 3: Preprocessing
train_select_evaluate.py Pipeline — fit on TRAIN ONLY
  • All fit() on train only, transform() on valid/test MLGG-P01 Kaufman 2012
  • Auto categorical encoding (fit on train):
    • Binary (2 values) → 0/1 mapping, OOD → 0.5 sentinel
    • Categorical (3-15 values) → OneHot, OOD → all-zero row
    • Numeric (> 15 unique) → unchanged MLGG-P05 encode_categorical_features()
  • Tiered missingness strategy:
    • Tier 4 (>80%): drop value, keep missing indicator
    • Tier 3 (40-80%): impute + indicator
    • Tier 2 (5-40%): impute + indicator
    • Tier 1 (<5%): simple imputation MLGG-P06 Madley-Dowd 2019
  • Pipeline: Imputer → Scaler → Classifier
    IterativeImputer (MICE) or SimpleImputer, per scale guard
  • No SMOTE by default — harms calibration van den Goorbergh 2022
→ X_train/X_valid/X_test (encoded, imputed)  |  preprocessor.pkl
P4
Phase 4: Feature Selection & Diagnostics
train_select_evaluate.py — train only
  • Elastic Net CV: α ∈ {0.1, 0.3, 0.5, 0.7, 1.0}, C cross-validated
    Group selection: OneHot dummies from same variable selected/dropped together Zou & Hastie 2005 Yuan & Lin 2006
  • Stability Selection: 100 subsamples × Elastic Net
    Keep features with inclusion probability > 0.6
    False selection bound: E[V] ≤ q² / ((2π-1) × p) Meinshausen 2010
  • Ridge baseline comparison: if Elastic Net selection costs > 0.005 PR-AUC, revert to full Ridge Harrell 2015
  • VIF multicollinearity check (auto-run):
    VIF > 5 → WARNING, VIF > 10 → CRITICAL compute_vif()
  • Nonlinearity test: LR test (linear vs spline) per continuous feature
    p < 0.05 → nonlinear relationship detected check_nonlinearity()
  • Univariate pre-screening DEPRECATED Heinze 2018
→ selected_features  |  vif_analysis  |  nonlinearity_analysis  |  feature_engineering_report.json
P5
Phase 5: Model Training & Selection
train_select_evaluate.py — 20 model families
  • Compare ≥ 3 model families:
    LR (L1/L2/ElasticNet) | RF | XGBoost | LightGBM | CatBoost | SVM | KNN | MLP | TabPFN + ensembles MLGG-M03
  • Hyperparameter tuning on VALIDATION set only, never test
    5-fold StratifiedKFold CV for inner loop (Optuna TPE or grid search) MLGG-M01
  • Model selection: validation PR-AUC, NOT train-test gap
    One-SE rule: within 1 SE of best, choose simplest model MLGG-M04 Yang KDD 2023
  • Threshold: Youden's J on validation set
    J = Sensitivity + Specificity - 1, threshold* = argmax J(t) MLGG-M02
  • Bootstrap optimism correction (Steyerberg 2019 Ch.17):
    B ≥ 100 bootstrap samples → optimism-corrected performance Steyerberg 2019
  • Learning curve: performance at {10%, 20%, ..., 100%} training data learning_curve_data()
  • Save model pool for SHAP: best-per-family models
    --model-pool-out evidence/model_pool.pkl
→ model.pkl  |  model_pool.pkl  |  model_selection_report.json  |  thresholds.json
P6
Phase 6: Evaluation & Calibration
train_select_evaluate.py + 13 statistical gates — Layer 6
  • Test set: single-use, never retrained
    Full 5-domain metric panel (Lancet DH 2025): Van Calster 2025
  • Discrimination: AUROC, AUPRC
    Calibration: intercept (→0), slope (→1), O:E (→1), ECE, Hosmer-Lemeshow χ²
    Overall: Brier score, Brier Skill Score (>0 = better than prevalence)
    Classification: MCC, LR+/LR-, Sensitivity, Specificity, PPV, NPV, F1
    Clinical utility: DCA net benefit, NRI, IDI MLGG-E02 calibration_metrics() compute_nri_idi()
  • 95% CI for ALL metrics: percentile bootstrap ≥ 1000 MLGG-E01
  • Calibration per-bin with bootstrap CI (NC Reviewer #2) calibration_bin_ci()
  • Post-hoc calibration: Platt scaling on validation → apply to test
    class_weight="balanced" requires mandatory recalibration MLGG-E05
  • Multi-seed stability: ≥ 5 seeds, std(AUROC) < 0.02 MLGG-R02
  • Baseline comparisons: vs prevalence model, random, all-pos, all-neg baseline_comparisons()
  • Feature ablation: remove top-N features, measure performance drop feature_ablation()
  • Model coefficients export: LR coef_ or tree feature_importances_ export_model_coefficients()
  • Compute resource report: wall time, hardware info compute_resource_report()
→ evaluation_report.json  |  prediction_trace.csv.gz  |  ci_matrix_report.json  |  calibration curves
P7
Phase 7: Multi-Model SHAP Interpretability
shap_interpretability_gate.py — Layer 5
  • Multi-family SHAP: compute independently for each model family
    • TreeExplainer: RF, XGBoost, CatBoost, LightGBM
    • LinearExplainer: Logistic Regression
    • KernelExplainer: SVM, KNN, MLP (fallback) Lundberg 2017/2020
  • Proportional normalization ensemble:
    Per-model: mean(|SHAP|) → L1 normalize (sum=1) → proportion
    Ensemble: equal-weight average of proportions across families
    Eliminates scale differences between model families PMC11513550
  • Cross-model agreement:
    • Kendall τ rank correlation (>0.7 strong, 0.5-0.7 moderate, <0.5 weak)
    • Top-N Jaccard overlap coefficient
    • Direction consensus: positive / negative / mixed
  • Individual case explanations: top-K highest + lowest risk
    Top-3 driving features per case with SHAP values
  • 8 validation checks: NaN, all-zeros, single model, rank disagreement, extreme concentration, suspicious features, feature mismatch, shap import
→ Table A: ensemble importance  |  Table B: per-model detail  |  Table C: rank agreement  |  Table D: case explanations
→ shap_interpretability_report.json
P8
Phase 8: Fairness & Subgroup Analysis
fairness_equity_gate.py — Layer 6
  • Subgroup analysis by protected attributes: race, gender, age
    Per-group: AUROC, AUPRC, Sensitivity, Specificity, PPV, FPR MLGG-Q01
  • Subgroup-specific DCA: net benefit per demographic group
    Equity gap: max - min optimal net benefit across groups
    Model may help majority but harm minority subgroup_dca() Vickers 2025
  • Small subgroup flagging: n < 200 → estimates unreliable MLGG-Q02
  • Disparity thresholds:
    AUROC max-min > 0.05 → WARNING
    Sensitivity max-min > 0.10 → WARNING
→ subgroup_race.csv  |  subgroup_gender.csv  |  subgroup_age.csv  |  fairness_equity_report.json
P9
Phase 9: Reporting & Publication Gate
publication_gate.py + self_critique_gate.py — Layer 7-8
  • TRIPOD+AI 2024 checklist: 27 items machine-verified Collins 2024 BMJ
  • PROBAST+AI 2025: 4-domain bias risk assessment (16/18 signaling questions) Moons 2025 BMJ
  • 12-dimension quality scoring (0-100):
    Data Integrity (12) | Leakage Prevention (15) | Pipeline Isolation (12) | Model Selection (10)
    Statistical Validity (12) | Generalization (10) | Clinical Completeness (7) | Reporting (7)
    Reproducibility (6) | Security (3) | Fairness (3) | Sample Size (3)
    ≥90 publication-grade | 75-89 needs work | <60 unpublishable
  • Model Card auto-generation generate_model_card()
  • Limitations: must discuss data source, temporal validity, external validity, fairness caveats
    If DCA shows no clinical utility → report honestly
→ publication_gate_report.json  |  self_critique_report.json  |  model_card.md  |  TRIPOD checklist
