P1
数据理解与队列定义
cohort_definition_gate.py · Layer 0
  • 加载 CSV → 验证 target 为 0/1 二分类
  • 定义合格队列：排除结局不可能记录 MLGG-C01
    例: 死亡患者不可能再入院
  • Riley 2019 样本量三准则 Riley 2019 Stat Med
    C1: 收缩因子 ≥ 0.9 · C2: R² optimism ≤ 0.05 · C3: 精度
    EPV < 5 → FAIL · 5-10 → WARN
    riley_sample_size()
  • 数据类型自动检测: numeric / binary / categorical
  • 缺失值概况: 按特征统计, >50% 标记
  • 横截面 vs 纵向: 患者ID有重复? → 纵向
→ cohort_summary.csv · feature_profile.csv · JSON报告
P2
数据划分
split_data.py · split_protocol_gate.py · Layer 3
  • 患者级 disjoint: 同一患者 → 同一 split MLGG-S01
    任何 ID 重叠 → FAIL
  • 横截面数据?
    是 → stratified_grouped + --cross-sectional
    按标签分层, 层内随机, 跳过时序检查
    否 → grouped_temporal MLGG-S02
    按时间排序: train < valid < test
  • 比例: Train 60% / Valid 20% / Test 20%
  • 安全检查: ≥20行, ≥10正/负, ≥5患者
    正类率漂移 >10% → ⚠️
→ train.csv · valid.csv · test.csv · split报告
P3
预处理 (fit on TRAIN ONLY)
train_select_evaluate.py Pipeline
  • 所有 fit() 仅在训练集 MLGG-P01 Kaufman 2012
  • 自动分类编码 (fit on train) MLGG-P05
    Binary(2值) → 0/1, OOD → 0.5 sentinel
    Categorical(3-15值) → OneHot, OOD → 全零行
    Numeric(>15值) → 保持原值
    encode_categorical_features()
  • 分层缺失策略 MLGG-P06 Madley-Dowd 2019
    Tier4(>80%): 丢弃+指示 · Tier3(40-80%): 插补+指示
    Tier2(5-40%): 插补+指示 · Tier1(<5%): 简单插补
  • Pipeline: Imputer → Scaler → Classifier
  • SMOTE 默认不用 → 损害校准 van den Goorbergh 2022
→ X_train/valid/test (编码+插补) · preprocessor.pkl

P4
特征筛选与诊断
train_select_evaluate.py · train only
  • Elastic Net CV Zou & Hastie 2005
    α ∈ {0.1, 0.3, 0.5, 0.7, 1.0}, C 交叉验证
    分组选择: OneHot dummies 同进同退 Yuan & Lin 2006
  • 稳定性选择 Meinshausen 2010
    100次子采样, 保留入选概率 > 0.6
    误选界: E[V] ≤ q²/((2π-1)×p)
  • Ridge 对照 Harrell 2015
    选择损失 > 0.005 PR-AUC → 回退全量
  • VIF 共线性 (自动) compute_vif()
    >5 ⚠️ | >10 🔴
  • 非线性检验 (自动) check_nonlinearity()
    LR test: 线性 vs 样条, p<0.05 → 非线性
  • 单因素筛选已废弃 Heinze 2018
→ selected_features · VIF分析 · 非线性分析 · 报告
P5
模型训练与选择
train_select_evaluate.py · 20个模型族
  • ≥3 模型族 MLGG-M03
    LR | RF | XGBoost | LightGBM | CatBoost
    SVM | KNN | MLP | TabPFN | 集成
  • 验证集调参, 绝不碰 test MLGG-M01
    5折 StratifiedKFold · Optuna TPE
  • 模型选择: valid PR-AUC, 不用 gap Yang KDD 2023
    One-SE 规则: 1SE 内选最简单 MLGG-M04
  • 阈值: Youden's J on valid MLGG-M02
    J = Sens + Spec - 1
  • Bootstrap optimism correction Steyerberg 2019
    B ≥ 100 · optimism-corrected performance
  • 学习曲线 learning_curve_data()
    {10%, 20%, ..., 100%} 训练比例 → 收敛?
  • 保存模型池 → SHAP 用
    --model-pool-out model_pool.pkl
→ model.pkl · model_pool.pkl · 选择报告 · thresholds
P6
评估与校准
13 道统计门控 · Layer 6
  • Test 集一次性评估, 5 域面板 Lancet DH 2025
  • 区分度: AUROC, AUPRC
  • 校准: 截距→0 · 斜率→1 · O:E→1
    ECE · HL χ² · per-bin 95% CI Van Calster 2019
    calibration_metrics() · calibration_bin_ci()
  • 整体: Brier · BSS (>0=优于基线)
  • 分类: MCC · LR+/LR- · Sens/Spec/PPV/NPV Chicco 2020
  • 临床: DCA · NRI · IDI compute_nri_idi()
  • 95% CI: bootstrap ≥ 1000 MLGG-E01
  • 多种子: ≥5 seeds, std < 0.02 MLGG-R02
  • Platt scaling 事后校准 MLGG-E05
  • 基线对比 baseline_comparisons()
  • 特征消融 feature_ablation()
  • 系数导出 export_model_coefficients()
  • 计算资源 compute_resource_report()
→ evaluation_report · prediction_trace · CI矩阵 · 校准曲线

P7
多模型 SHAP 可解释性
shap_interpretability_gate.py · Layer 5
  • 多族独立 SHAP Lundberg NeurIPS 2017
    TreeExplainer: RF/XGB/CatBoost/LGBM
    LinearExplainer: LR · KernelExplainer: 兜底
    背景: train 200行 · 解释: test 500行
  • 比例归一化集成 PMC11513550
    每模型 mean(|SHAP|) → L1归一化(sum=1)
    跨模型等权平均 → 消除尺度差异
  • 一致性检验
    Kendall τ: >0.7强 | 0.5-0.7中 | <0.5弱
    Top-N Jaccard 重叠 · 方向共识
  • 个案解释: 高/低风险 Top-3 驱动特征
  • 8 项自动验证: NaN/全零/单模型/排名分歧/极端集中/可疑特征
→ Table A(集成排名) · B(逐模型) · C(一致性) · D(个案)
P8
公平性与亚组分析
fairness_equity_gate.py · Layer 6
  • 按 race / gender / age 分组 MLGG-Q01
    每组: AUROC / AUPRC / Sens / Spec / PPV / FPR
  • 亚组 DCA 净效用 Vickers 2025
    按人群分组计算 DCA 净效用
    equity gap = max - min 最优净效用
    模型可能帮助多数但伤害少数!
    subgroup_dca()
  • 小亚组标记: n < 200 → 不可靠 MLGG-Q02
  • 差异标记
    AUROC 差异 >0.05 → ⚠️
    Sens 差异 >0.10 → ⚠️
→ subgroup_race/gender/age.csv · fairness报告
