  • 缺失值概况: 按特征统计, >50% 标记

P2
数据划分
split_data.py · split_protocol_gate.py · Layer 3
  • 患者级 disjoint: 同一患者 → 同一 split MLGG-S01

    是 → stratified_grouped + --cross-sectional
    否 → grouped_temporal MLGG-S02
  • 比例: Train 60% / Valid 20% / Test 20%
  • 安全检查: ≥20行, ≥10正/负, ≥5患者

P3
预处理 (fit on TRAIN ONLY)
preprocess.py · encoding_groups.json → Phase 4
  • 所有 fit() 仅在训练集 MLGG-P01 Kaufman 2012
  • 基数+dtype 列类型检测 MLGG-P05
    Binary(2值) → 0/1 映射
    Categorical(string, 3-15值) → OneHot
    Numeric(int/float, 任意基数) → 保持原值
    计数变量(num_meds=0-11)不展开OneHot
  • 4 层缺失策略 MLGG-P06 Madley-Dowd 2019
    T4(>80%): 丢值+指示 · T3(40-80%): 插补+指示
    T2(5-40%): 插补+指示 · T1(<5%): 简单插补
  • 输出 encoding_groups.json → Phase 4 Group LASSO
  • SMOTE 默认不用 van den Goorbergh 2022
  • 📚 24/375 NC 审稿意见涉及 preprocessing
→ processed_data.npz · feature_names.json · encoding_groups.json · missingness_report.json

P4
特征筛选 (train only)
select_features.py · 6 步流水线
  • MLGG-F01/F02: 禁止特征检查（标签泄漏 + 未来信息）
  • NZV 过滤: >99% 相同值 → 移除
  • Ridge 基线 (CV 调优 6 个 C 值) Harrell 2015
    PR-AUC 作为对比标准 Saito & Rehmsmeier 2015
  • Stability Selection Meinshausen 2010
    Elastic Net α∈{0.1-1.0}, class_weight=balanced
    100 次分层子采样, 阈值 0.6
    Group LASSO: OneHot dummy 同进同退 Yuan & Lin 2006
    误选界: E[V] ≤ q²/((2πθ-1)×p)
  • 选择后 PR-AUC 降 >0.005 → 回退 Ridge 全量
  • EPV 重检: 选择后仍 ≥ 10 MLGG-Z01
  • 单因素筛选已废弃 Heinze 2018
  • 📚 PR-016: "24参数87样本=过参数化"
→ selected_data.npz · selected_features.json · stability_selection.csv · selection_report.json

    One-SE 规则: 1SE 内选最简单 MLGG-M04
  • 阈值: Youden's J on valid MLGG-M02
  • Bootstrap optimism correction Steyerberg 2019
  • 学习曲线: 收敛? learning_curve_data()
  • 📚 PR-029: "XGBoost=Transformer → 选简单的"

P6
评估与校准
13 道统计门控 · Layer 6
  • Test 集一次性评估, 5 域面板 Lancet DH 2025
  • 区分度: AUROC, AUPRC
  • 校准: 截距→0 · 斜率→1 · O:E→1
    ECE · HL χ² Van Calster 2019
  • 整体: Brier · BSS (>0=优于基线)
  • 分类: MCC · LR+/LR- · Sens/Spec/PPV/NPV Chicco 2020
  • 临床: DCA · NRI · IDI compute_nri_idi()
  • 95% CI: bootstrap ≥ 1000 MLGG-E01
  • 多种子: ≥5 seeds, std < 0.02 MLGG-R02
  • Platt scaling 事后校准 MLGG-E05
  • 📚 119/375 NC 审稿意见要求完善评估指标

P8
公平性与亚组分析
fairness_equity_gate.py · Layer 6 · 8 项 D11 标准
  • 保护属性覆盖: age + sex + race/ethnicity (±保险) PROBAST+AI D5.3
    缺少关键人口统计维度 → 审稿人必问
  • 均等化优势差距 < 0.15 D11.2
    max sensitivity gap across subgroups
    Nature Medicine / JAMA / BMJ 强制要求
  • 差异影响比 > 0.80 (四分之五规则) D11.3
    min(subgroup_rate) / max(subgroup_rate)
  • FPR / FNR 均等差距 < 0.15 D11.6/D11.7
    HEAL framework (eClinicalMedicine 2024)
  • 亚组最低 PR-AUC > 0.40 D11.x
    防止"平均好但少数群体极差"
  • 亚组 DCA 净效用 subgroup_dca()
    equity gap = max - min 净效用
  • 小亚组: n < 50 → 不稳定 · n < 20 → 不可靠 D11.4
  • 不可能定理声明: ≥3 指标时必须说明优先级 D11.8
  • 如有偏差: 必须记录缓解策略 D11.5
    阈值校准 / 公平约束优化 / 子组模型
  • 📚 43/375 NC 审稿意见涉及公平性/偏倚
    最常见: 缺少人口统计(11) · 亚组遗漏(12) · 性别混杂(8)
