# Nature Communications — Peer Review Files (Medical ML)

透明同行评审文件，收集自 Nature Communications 发表的医学机器学习预测模型论文。
包含完整的审稿人意见、作者回复和修改说明。

## 用途

- 了解顶刊审稿人对医学 ML 论文的常见质疑
- 学习作者如何回应方法学挑战（数据泄漏、校准、外部验证等）
- 作为 MLGG 规则的实证依据
