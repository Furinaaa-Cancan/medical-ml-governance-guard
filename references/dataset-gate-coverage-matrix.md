## 不可测的 Gate

以下 gate 在当前数据集上无法端到端验证：

| Gate | 原因 | 需要什么 |
|------|------|---------|
| `external_validation_gate` | 所有数据集均为单一来源，无独立外部队列 | 需要 MIMIC→eICU 或 NHANES→KNHANES 跨库验证 |
| `reporting_bias_gate` | 需要 TRIPOD+AI checklist 输入，非纯数据层面 | 需要人工填写 reporting checklist |

## 分层报告要求

在发表结果时，应按档次分层报告：
- A 档（29/31 覆盖）：报告全部 gate 结果
- B 档（21-26/31）：报告可测 gate 结果，标注不可测 gate
- C 档（12/31）：仅报告基础 gate（split、leakage、contract），明确声明大部分 gate 未激活

**禁止**：将 C 档数据集的"全部 gate 通过"解读为"框架验证成功"——因为多数 gate 根本没运行。
